## 三、发布后检查
检查目录：

```text
05输出层/exports/
├── releases/{release_id}/
│   ├── stock_alpha.parquet
│   └── manifest.json
└── current.json
```

检查内容：
1. `current.json.release_id` 等于本次发布 ID
2. manifest 中 `source_exp_id` 正确
3. `data_start`、`data_end` 与实验预测一致
4. `row_count` 与 Parquet 行数一致
5. 输出不含 `actual_return`
6. `alpha_rank` 范围正确
7. SHA256 字段存在
---
## 四、历史版本与复现
历史 release 不删除、不覆盖。组合仓库：
- 日常运行读取 `current.json`
- 历史复现显式指定 `release_id`

`current.json` 只表示当前默认版本，不代表历史 release 的排序。
---
## 五、故障排查
| 现象 | 原因 | 处理 |
|:---|:---|:---|
| 找不到实验目录 | `exp-id` 错误 | 使用 experiments 下实际目录名 |
| 找不到平滑预测 | 实验未完成 | 等训练完成并检查输出 |
| release 已存在 | ID重复 | 使用新的 release ID |
| 主键重复 | 预测链异常 | 返回训练层排查，不在输出层去重 |
| Alpha 含空值/无穷值 | 来源预测异常 | 停止发布并检查实验 |
| current 指向异常 | 发布中断或文件被手改 | 检查 release 和 manifest 后修复 |
| 内存不足 | 正式预测行数较大 | 避免与全量模型训练并发 |
