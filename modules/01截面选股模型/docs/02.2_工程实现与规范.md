## 四、财务PIT与TTM
### 4.1 输入
```text
01数据/data/tushare_data/financial_full/{table}/{period}.parquet
```

### 4.2 版本选择
对每个交易日、股票、报告期：
1. 过滤公告日在交易日之后的记录
2. 按 `f_ann_date` 更新该报告期的当前版本
3. 同日 type 1/type 5 冲突时选择 type 5
4. 从公告后的第一个交易日使用新版本
5. 保留报告期顺序，再计算基础字段和派生字段

### 4.3 流量字段
利润表和现金流量表累计值：

```python
q1 = cumulative_q1
q2 = cumulative_q2 - cumulative_q1
q3 = cumulative_q3 - cumulative_q2
q4 = annual - cumulative_q3
ttm = q[t] + q[t-1] + q[t-2] + q[t-3]
```

要求最近四个季度完整且顺序正确。

### 4.4 时点字段
资产负债表字段直接使用交易日当时最新已披露期末值。

### 4.5 公告日期
优先使用实际公告日期字段；字段缺失时按加载器定义的兼容规则处理。任何 fallback 都必须记录，不能使用未来公告日期回填过去。

## 九、因子开发规范
### 9.1 命名
- 小写snake_case
- 文件名、函数名和模型特征名一致
- 窗口参数写入名称，例如`ret20`

### 9.2 Docstring
必须说明：
- 经济逻辑
- 输入字段
- 公式
- 窗口
- 预期方向
- 缺失条件

### 9.3 新因子流程
1. 确认基础字段PIT正确
2. 在对应家族实现
3. 注册到计算入口
4. 运行单因子检查
5. 执行截面清洗
6. 检查分布、缺失率和未来函数
7. 再加入训练

### 9.4 删除因子
- 从注册表删除
- 删除或归档产物
- 记录原因和影响
- 使用新实验ID重新训练

## 十、常见问题
| 问题 | 原因 | 处理 |
|:---|:---|:---|
| 财务因子整段为空 | TTM季度不足或版本选择失败 | 检查基础宽表 |
| 同一报告期历史值变化 | 错用后续修订 | 检查PIT选择 |
| 因子轴不一致 | 基础宽表日期/股票不同 | 运行迁移验证 |
| 标准差不接近1 | 有效样本太少或常量截面 | 检查当日分布 |
| gross_margin找不到 | 已从当前库删除 | 不再引用 |
| 训练仍读旧因子 | 未重建processed_data | 运行update_all |
