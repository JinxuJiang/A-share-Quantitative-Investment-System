## 三、因子新增和重算
### 3.1 新增
1. 确认经济逻辑
2. 确认基础字段PIT
3. 在正确家族实现
4. 注册计算入口
5. 生成单因子文件
6. 检查分布和缺失
7. 运行训练前验证

### 3.2 重算
直接运行对应家族主入口。不要用手工拼接方式覆盖部分日期，除非实现已经明确支持原子增量。

### 3.3 删除
删除因子后：
- 更新因子清单
- 更新README和docs
- 使用新实验ID重训
- 保留变更原因

## 五、故障排查
| 现象 | 检查 |
|:---|:---|
| 因子日期没更新 | 基础宽表是否重建 |
| 财务值在公告前出现 | PIT版本选择 |
| TTM跳变 | 单季度差分和报告期顺序 |
| 大量股票被删除 | 缺失值阈值和清洗规则 |
| 某因子全空 | 上游基础字段 |
| 模型特征数量不是45 | 因子目录残留或缺文件 |
