# 03.3 模型训练层运维与变更日志
> Quarterly PIT V2 的检查点、训练运维、复现规则和变更记录。
---
## 一、关键检查点
### 1.1 训练前
| 检查项 | 通过标准 |
|:---|:---|
| 因子目录 | 21个技术+24个财务因子 |
| 行情日期 | 覆盖目标end_date |
| ST路径 | 指向`tushare_data/st_status.parquet` |
| Production配置 | 不包含个人绝对路径 |
| horizon/gap | gap=horizon+1 |
| exp-id | 参数变化时使用新ID |

### 1.2 训练中
- 每个季度输出清晰的训练、验证和预测边界
- 样本数量不存在异常突降
- early stopping 正常触发或达到最大轮数
- 进程持续产生季度模型或明确记录复用
- 内存占用稳定

### 1.3 训练后
| 检查项 | 通过标准 |
|:---|:---|
| `quarterly_splits.parquet` | 覆盖目标季度 |
| `predictions.parquet` | date+stock_code无重复 |
| `smoothed_predictions.parquet` | 行数与主预测一致 |
| `summary.parquet` | 每个季度唯一 |
| 模型文件 | 与已训练季度对应 |
| manifest | 配置哈希和完成季度完整 |
| 最新不可评价样本 | `actual_return`为空且`is_evaluable=False` |

### 1.4 指标检查
- 日度 Rank IC 均值
- Rank IC 正值占比
- 不同季度 IC 稳定性
- 预测截面标准差
- 特征重要性集中度
- Top20股票风格漂移

单一高 IC 不能替代稳定性和可执行性检查。

## 二、标准运维流程
### 2.1 新完整实验
1. 确认因子层验收通过
2. 确认 production 配置
3. 使用新 `exp-id`
4. 从目标历史起点运行
5. 检查季度产物持续生成
6. 完成后执行指标验收
7. 再进入融合和回测

### 2.2 月度增量
1. 更新01层数据
2. 重建02层宽表和因子
3. 使用相同production配置
4. 使用相同`exp-id`
5. 增加新的`end-date`
6. 加`--freeze`
7. 比较历史预测是否保持不变

### 2.3 参数更新
参数更新后：
- 晋升新的 production 配置
- 使用新的实验 ID
- 不覆盖旧实验
- 在变更日志中记录 study 和 trial

### 2.4 复现实验
复现所需最小集合：

```text
Git commit
production config
experiment/config.yaml
quarterly_splits.parquet
freeze_manifest.json
数据截止日
```

## 三、Freeze一致性
### 3.1 历史预测检查
同一个 Freeze 实验增量前后，对旧日期比较：

```text
date + stock_code + pred_score
```

要求旧日期完全一致。

### 3.2 模型复用检查
已有季度的：

```text
state/models/model_YYYYQn.pkl
```

不应在普通增量运行中重写。

### 3.3 配置哈希失败
出现配置哈希不一致时：
- 如果确实换了参数：新建exp-id
- 如果需要重建同一实验：明确使用`--reset-freeze`
- 不要手工修改manifest绕过检查

## 四、调参运维
### 4.1 调参前
- 选择与目标 horizon 一致的基准配置
- 确认代表季度不全部集中在单一市场状态
- 固定随机种子
- 记录 trial 数量

### 4.2 调参后
- 检查 Top trial 是否只在个别季度领先
- 执行非重合季度验证
- 检查邻近参数扰动
- 生成最终推荐配置
- 晋升到 production

## 六、性能与资源
当前本机实验目录约 1.8GB，完整历史训练耗时依赖：
- 预测起止日期
- horizon和Gap
- 季度数量
- LightGBM最佳迭代轮数
- 是否使用Freeze复用

性能基准应从实际日志记录，不在文档中固定写死。

运行监控：

```powershell
Get-CimInstance Win32_Process |
  Where-Object { $_.CommandLine -match 'main_train_v2.py' } |
  Select-Object ProcessId, CreationDate, CommandLine
```

## 七、故障排查
| 现象 | 处理 |
|:---|:---|
| 长时间无新模型 | 检查CPU、内存、日志和当前季度数据构造 |
| 模型文件极小 | 检查特征数、最佳迭代轮数和训练失败 |
| Freeze不追加 | 检查目标end_date与已有日期 |
| 历史预测变化 | 停止验收，检查是否重置Freeze或更换输入 |
| IC突然反向 | 检查标签、数据源、因子轴和股票池 |
| 最后日期无actual | 标签尚未兑现，属于正常 |
