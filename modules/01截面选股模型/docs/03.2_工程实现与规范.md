# 03.2 模型训练层工程实现与规范
> 本文档描述 Quarterly PIT V2 的 API、配置、运行命令、输出格式和开发规范。
---
## 一、核心组件
### 1.1 DataConstructorV1
文件：

```text
dataset/data_constructor_v1.py
```

职责：
- 扫描技术和财务因子
- 加载 open/close 行情
- 计算 open-to-open 标签
- 加载 ST 状态
- 构建指定日期的截面 X/y
- 对训练和验证样本应用利润过滤

主要配置：

```yaml
data:
  factor_paths:
    technical: 02因子库/processed_data/factors/technical
    financial: 02因子库/processed_data/factors/financial
  market_data_path: 02因子库/processed_data/market_data
  open_column: open
  st_status_path: 01数据/data/tushare_data/st_status.parquet
  profit_filter_pct: 0.2
  label:
    horizon: 20
    use_open_price: true
```

### 1.2 QuarterlySplitterV2
文件：

```text
dataset/quarterly_splitter_v2.py
```

输出每个季度的：
- `model_period`
- `train_start`
- `train_end`
- `valid_start`
- `valid_end`
- `period_start`
- `period_end`
- `fold_id`

### 1.3 QuarterlyTrainerV2
文件：

```text
training/quarterly_trainer_v2.py
```

职责：
- 创建实验目录
- 保存实际配置快照
- 生成季度切分
- 训练或复用季度模型
- 生成预测和季度摘要
- 保存特征重要性
- 平滑预测
- 更新 Freeze manifest

### 1.4 LightGBMModel
文件：

```text
models/lightgbm_model.py
```

统一接口：

```python
model.fit(X_train, y_train, X_valid, y_valid)
pred = model.predict(X)
importance = model.get_feature_importance()
model.save(path)
```

## 二、配置规范
### 2.1 基准配置
```text
configs/horizon5_config.yaml
configs/horizon20_config.yaml
configs/horizon60_config.yaml
```

用途：
- 开发基线
- 调参起点
- 参数对照

### 2.2 Production配置
```text
configs/production/horizon5_profit20_tuned_config.yaml
configs/production/horizon20_profit20_tuned_config.yaml
configs/production/horizon60_profit20_tuned_config.yaml
```

要求：
- 路径必须相对项目根目录
- 保存完整 `quarterly_v2`
- 保存 `tuning_metadata`
- 文件名包含 horizon 和主要筛选口径
- 正式训练统一使用该目录

### 2.3 调参原始配置
```text
tuning/tuning_results/{study_name}/final_recommended_config.yaml
```

该文件是调参程序原始输出，不直接作为长期正式入口。

晋升规则：
1. 复制模型和训练参数
2. 保留 `tuning_metadata`
3. 把绝对数据路径改为项目相对路径
4. 保存到 `configs/production/`
5. 不修改原始调参结果

### 2.4 Quarterly V2配置
```yaml
quarterly_v2:
  train_window: 3Y
  valid_window: 2M
  gap: 21
  smooth_halflife: 10
```

`gap` 应默认等于 `horizon + 1`。

## 三、正式训练
以下命令均在项目根目录执行。

### 3.1 20日模型
```powershell
python 03模型训练层/main_train_v2.py `
  --config horizon20_profit20_tuned_config.yaml `
  --exp-id lgbm20_tushare_profit20 `
  --start-date 2020-01-01 `
  --freeze -y
```

注意：`main_train_v2.py` 会把相对 `--config` 解释为相对 `03模型训练层/`，因此不要重复写 `03模型训练层/configs/...`。

### 3.2 5日模型
```powershell
python 03模型训练层/main_train_v2.py `
  --config configs/production/horizon5_profit20_tuned_config.yaml `
  --exp-id lgbm5_tushare_profit20 `
  --start-date 2020-01-01 `
  --freeze -y
```

### 3.3 60日模型
```powershell
python 03模型训练层/main_train_v2.py `
  --config horizon60_profit20_tuned_config.yaml `
  --exp-id lgbm60_tushare_profit20 `
  --start-date 2020-01-01 `
  --freeze -y
```

### 3.4 As-of运行
```powershell
python 03模型训练层/main_train_v2.py `

  --exp-id lgbm20_asof_20260701 `
```

### 3.5 月度增量

## 四、命令行参数
| 参数 | 类型 | 说明 |
|:---|:---|:---|
| `--config` | string | YAML配置 |
| `--exp-id` | string | 实验ID，自动追加`_v2` |
| `--start-date` | date | 预测开始日 |
| `--end-date` | date | 数据/as-of截止日 |
| `--train-window` | string | 覆盖训练窗口 |
| `--valid-window` | string | 覆盖验证窗口 |
| `--gap` | int | 覆盖交易日Gap |
| `--smooth-halflife` | float | 覆盖平滑半衰期 |
| `--horizon` | int | 覆盖标签周期 |
| `--freeze` | flag | 增量冻结模式 |
| `--reset-freeze` | flag | 重建同一实验Freeze状态 |
| `-y` | flag | 跳过确认 |

## 五、实验输出规范
### 5.1 目录
```text
experiments/{exp_id}_v2/
├── config.yaml
├── quarterly_splits.parquet
├── predictions.parquet
├── smoothed_predictions.parquet
├── summary.parquet
├── quarterly_rank_ic_v2.png
├── feature_importance_v2.png
├── models/
├── feature_importance/
└── state/
```

### 5.2 predictions.parquet
主要字段：
| 字段 | 说明 |
|:---|:---|
| date | 预测日期 |
| stock_code | 股票代码 |
| pred_score | 原始预测 |
| actual_return | 已兑现时的真实标签 |
| is_evaluable | 当前是否可计算IC |
| model_period | 季度模型 |
| fold_id | 季度序号 |

### 5.3 smoothed_predictions.parquet
与原始预测结构一致，增加：

```text
pred_score_smooth
```

### 5.4 summary.parquet
记录：
- 季度边界
- 训练和验证样本
- 日度 Rank IC 均值
- 模型周期
- 训练状态

### 5.5 Freeze manifest
```json
{
  "exp_id": "lgbm20_tushare_profit20_v2",
  "config_hash": "...",
  "periods": {},
  "updated_at": "2026-07-30 18:00:00"
}
```

不要手工编辑 manifest。

## 六、调参
### 6.1 参数搜索
```powershell
python 03模型训练层/tuning/tune_lgbm_v2.py `
  --base-config 03模型训练层/configs/horizon20_config.yaml `
  --study-name lgbm20_v2_example `
  --n-trials 20
```

代表季度默认覆盖不同市场阶段，避免每个 trial 执行全历史训练。

### 6.2 稳健性验证
```powershell
python 03模型训练层/tuning/validate_lgbm_v2_params.py `
  --study-name lgbm20_v2_example `
  --base-config 03模型训练层/configs/horizon20_config.yaml `
  --top-k 3
```

验证包括：
- 非重合季度
- Top参数复验
- 邻近参数扰动
- 最终推荐配置生成

### 6.3 调参输出
```text
tuning/tuning_results/{study_name}/
├── study_results.csv
├── top_trials.csv
├── tuning_summary.md
├── validation_results.csv
└── final_recommended_config.yaml
```

Git 默认只保留最终推荐配置，运行时 CSV 和总结属于本地调参产物。

## 七、多周期融合
```powershell
python 03模型训练层/fuse_predictions.py `
  --exps lgbm5_tushare_profit20_v2 lgbm20_tushare_profit20_v2 lgbm60_tushare_profit20_v2 `
  --base-idx 1 `
  --output-exp ensemble_5d_20d_60d_profit20_v2
```

输入要求：
- 每个实验存在 `smoothed_predictions.parquet`
- 每个实验存在 `config.yaml`
- 股票代码和日期格式一致
- 标签公式和 `use_open_price` 口径一致；horizon 可以不同

输出：

```text
experiments/{output_exp}/
├── predictions.parquet
├── smoothed_predictions.parquet
├── config.yaml
└── fusion_config.yaml
```

融合实验的标准 `config.yaml` 使用 `base-idx` 对应模型的 horizon，可直接交给 04 回测层和 05 输出层；`fusion_config.yaml` 保留完整融合审计信息。

## 八、开发规范
### 8.1 新参数
- 先加入基准配置
- 明确是否进入 Freeze 配置哈希
- 更新 CLI 覆盖逻辑
- 增加配置快照检查

### 8.2 新模型
- 实现统一 `fit/predict/save/load`
- 明确 early stopping 输入
- 输出可比较的特征重要性或解释结果
- 使用新的实验 ID

### 8.3 数据修改
因子列表、标签、ST路径和利润过滤都属于关键输入。修改后不能继续写入旧 Freeze 实验。

### 8.4 日志
必须记录：
- 配置摘要
- 每季度边界
- 训练/验证样本数
- 最佳迭代轮数
- 预测行数
- Freeze复用和新增情况

## 九、常见问题
| 问题 | 原因 | 处理 |
|:---|:---|:---|
| 配置找不到 | `--config`重复写第三层前缀 | 使用`configs/...` |
| 自动出现`_v2` | 入口统一追加版本后缀 | 使用实际实验目录名 |
| Freeze配置哈希不一致 | 参数或输入变化 | 新建exp-id |
| 某季度没有模型 | 数据不足或边界无效 | 检查quarterly_splits |
| 最后一段actual_return为空 | 标签尚未兑现 | 正常，`is_evaluable=False` |
| 特征重要性图缺失 | 没有保存importance CSV | 检查训练配置 |
| 融合交集太小 | 日期或股票覆盖不一致 | 检查三个模型输入 |
