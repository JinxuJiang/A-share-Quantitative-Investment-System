## 三、Alphalens
### 3.1 运行
```powershell
python 04回测层/alphalens_analysis.py `
  --exp-id lgbm20_tushare_profit20_v2 `
  --periods 20 `
  --quantiles 10 `
  --use-smooth
```

### 3.2 参数
| 参数 | 默认 | 说明 |
|:---|:---|:---|
| `--exp-id` | 必填 | 实验目录 |
| `--periods` | 20 | 远期收益周期 |
| `--quantiles` | 10 | 分位数组数 |
| `--use-smooth` | false | 使用平滑预测 |

### 3.3 数据处理
```text
预测长表
  │
  ▼
MultiIndex(date, asset)
  │
  + 收盘价宽表
  ▼
get_clean_factor_and_forward_returns
```

### 3.4 输出
```text
reports/{exp_id}/
├── alphalens_report[_smooth].html
├── ic_analysis[_smooth].png
├── returns_analysis[_smooth].png
└── turnover_analysis[_smooth].png
```

## 四、Backtrader
### 4.1 参数配置
当前参数直接定义在代码：

```python
STRATEGY_PARAMS = {
    "stocks_per_batch": 20,
    "start_date": datetime(2023, 10, 1),
    "end_date": datetime(2026, 6, 30),
    "initial_cash": 50000,
    "commission": 0.002,
}
```

策略内部：

```python
stop_loss = 0.2
target_total_position = 0.90
```

### 4.2 运行
```powershell
python 04回测层/backtrader.eval.py `
  --exp-id lgbm20_tushare_profit20_v2 `
  --use-smooth
```

### 4.3 参数
| 参数 | 默认 | 说明 |
|:---|:---|:---|
| `--exp-id` | `exp_001` | 实验目录 |
| `--use-smooth` | false | 读取平滑预测 |

回测日期、资金、持仓数和手续费目前不能通过 CLI 覆盖。

### 4.4 数据加载
1. 读取主预测文件
2. 尝试读取旧 live 文件
3. live 文件不存在时使用空表继续
4. 合并 OHLCV 宽表
5. 删除行情缺失行

V2 只有单一 PIT 主预测链，因此第 2 步属于兼容遗留，后续应删除。

### 4.5 信号生成
```text
按月取首个交易日
  → 主板过滤
  → ST过滤
  → 有效数据>=20天
  → T+1开盘涨停过滤
  → prediction降序Top20
  → 生成买卖差集
```

### 4.6 策略执行
- 调仓日先处理卖出列表
- 买入列表按 90% 总仓位等权
- 每日检查止损
- Backtrader 记录订单成交

当前无显式滑点设置。

### 4.7 输出
```text
reports/{exp_id}/
├── rebalance_signals.csv
├── trades.csv
├── equity_curve.png
└── backtest_report.html
```

当前不生成 `performance.json`。

## 五、工程规范
### 5.1 路径
- 使用 `Path(__file__).parent.parent` 获取项目根
- 正式 ST 路径必须指向 `tushare_data`
- 不使用个人绝对路径

### 5.2 实验ID
CLI 接收的是实际目录名。V2 单模型通常以 `_v2` 结尾，融合实验是否带后缀取决于 `--output-exp`。

### 5.3 预测列
| 文件 | 列 |
|:---|:---|
| predictions | `pred_score` |
| smoothed_predictions | `pred_score_smooth` |

### 5.4 报告真实性
报告只列实际启用参数：
- 已启用手续费
- 未启用显式滑点
- 已启用20%止损
- 未启用行业中性和换手约束

### 5.5 最新日信号
T+1开盘涨停属于未来成交状态。在 T 日收盘生成候选信号时只能标注待开盘复核，不能假装已经知道 T+1 开盘价。

## 六、常见问题
| 问题 | 原因 | 处理 |
|:---|:---|:---|
| 报告写15%但结果按20% | 日志文案旧 | 以参数0.2为准并修正文案 |
| 没有performance.json | 当前代码未输出 | 不把它列为现有产物 |
| 最新日无法涨停过滤 | 没有T+1开盘价 | 开盘时二次过滤 |
