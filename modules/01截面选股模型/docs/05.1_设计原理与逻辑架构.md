# 05.1 输出层设计原理与逻辑架构
> 定位：把已经完成训练和回测验收的实验发布为稳定、可追溯、可由其他仓库读取的正式截面 Alpha。
---
## 一、层级职责
输出层负责：
- 读取人工选定的训练实验
- 将内部预测字段转换为稳定的下游契约
- 剔除未来收益和训练内部字段
- 保存不可覆盖的历史 release
- 记录来源、时间口径、Git 状态和文件校验值
- 维护当前默认正式 release 指针

来源实验既可以是单模型实验，也可以是训练层生成了标准 `config.yaml` 的融合实验。

输出层不负责：
- 训练或修改模型
- 自动判断哪个实验表现最好
- 读取回测报告生成 Alpha
- 组合优化、风险预算或目标权重计算

回测结果是人工验收依据，正式数据源仍是：

```text
03模型训练层/experiments/{exp_id}/
├── config.yaml
└── smoothed_predictions.parquet
```
---
## 二、逻辑架构
```text
03 模型训练层
experiments/{exp_id}/smoothed_predictions.parquet
                         │
                         │ 人工确认已经通过 04 层回测验收
                         ▼
              05输出层/publish_alpha.py
                         │
             字段映射 / 完整性检查 / 排名
                         │
                         ▼
05输出层/exports/
├── releases/{release_id}/
│   ├── stock_alpha.parquet
│   └── manifest.json
└── current.json
                         │
                         ▼
              后续组合仓库或研究系统
```
---
## 三、为什么需要独立输出层
训练实验目录属于模型内部实现，可能包含：
- 原始预测和平滑预测
- 真实未来收益
- 训练、验证和季度切分信息
- 模型文件与冻结状态

如果下游仓库直接读取实验目录，就会与训练层字段和目录结构强耦合，并可能误用 `actual_return`。

输出层只暴露稳定字段，让截面仓库与后续组合仓库通过文件契约通信，不跨仓库导入内部 Python 类。
---
## 四、发布与版本设计
### 4.1 正式发布
进入输出层的实验已经由用户完成验收，因此不再区分候选和正式版本。每次成功运行发布命令都视为正式发布。

### 4.2 不可变 release
每个 `release_id` 只允许创建一次：

```text
exports/releases/{release_id}/
```

如果目录已经存在，发布程序直接报错，禁止覆盖历史结果。

### 4.3 current 指针
`current.json` 不是排序文件，而是当前默认 release 的明确指针。每次发布成功后自动更新。

下游规则：
- 未指定 release：读取 `current.json`
- 指定 release：直接读取对应历史目录
---
## 五、Alpha 数据契约
`stock_alpha.parquet` 只包含：

| 字段 | 含义 |
|:---|:---|
| `signal_date` | 信号日期 |
| `stock_code` | Tushare 股票代码 |
| `alpha_score` | 平滑后的模型预测分数 |
| `alpha_rank` | 当日截面百分位，越接近 1 排名越高 |
| `horizon_days` | 模型预测周期 |

明确不发布：
- `actual_return`
- `is_evaluable`
- `train_start`、`train_end`
- `valid_start`、`valid_end`
- `fold_id` 和模型内部字段
---
## 六、信号时间口径
当前契约统一记录：

```text
signal_available_after = market_close
execution_lag_trading_days = 1
```

即 T 日因子和信号在收盘后完整可用，后续组合系统最早在 T+1 交易日执行。
---
## 七、仓库边界
截面仓库负责输出：

```text
股票 × 日期 → alpha_score / alpha_rank
```

后续组合仓库负责：
- 读取正式 Alpha
- 合并宏观市场状态
- 风险模型和协方差估计
- 权重优化与组合回测

输出层不产生目标仓位，也不下单。
