# 05 调仓输出层

本层读取组合优化层已发布版本中最近两期目标权重，生成供人工复核的理论调仓报告。报告不会连接券商账户，也不会直接提交订单。

## 输出内容

- `rebalance_report.html`：适合人工查看的调仓报告；
- `rebalance_actions.csv`：卖出、继续持有和新买入的结构化明细。

候选池内显示精确 `selection_rank`；排名缺失时，根据 `portfolio_summary.parquet` 中对应日期的 `candidate_stock_count` 动态显示“候选池规模 + 名外”。例如 Top30 策略中，第 21～30 名保留精确排名，候选池外显示“30名外”。

同一市场仓位档位下，继续持有股票的目标权重变化绝对值低于默认 0.5% 阈值时保持上期执行权重；市场仓位档位发生切换时不启用该阈值。

报告属于理论调仓清单。正式下单前仍需结合真实账户持仓、资金、价格和交易状态换算实际股数。
