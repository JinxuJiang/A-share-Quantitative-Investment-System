# 系统架构

## 模块边界

### 1. 截面选股模型

负责将行情、财务及估值数据加工为个股因子，并在严格 PIT 约束下训练多个预测周期的截面模型。最终输出带有日期、证券代码、预测分数及必要元数据的 Alpha 信号。

### 2. 市场仓位模型

负责从指数及宏观市场特征中识别市场状态，并将预测结果映射为目标总仓位。模型评估采用时间序列切分和独立的经济意义回测。

### 3. 组合优化与风控

负责对齐个股 Alpha 与市场仓位信号，在目标总仓位下施加个股、行业、换手及交易执行约束，输出组合权重、风险检查结果和调仓指令。

## 数据契约

三个模块通过版本化文件接口连接，不直接共享内部训练状态。截面和市场模型每日发布信号，组合层再依据官方交易日历生成相互独立的周度和月度轨道：

```text
Alpha 日度发布 + 市场仓位日度发布
                 │
                 ▼
           日度决策输入与校验
                 │
        ┌────────┴────────┐
        ▼                 ▼
   周度组合权重       月度组合权重
   5 日 VaR/ES       20 日 VaR/ES
        └────────┬────────┘
                 ▼
      风险缩放、回测与调仓报告
```

VaR 缩放只允许降低股票总仓位，不改变股票之间的相对权重，也不会把仓位放大到上游目标以上。当前默认风险预算为周度 7.5%、月度 15%。

完整生产编排由 `modules/03组合优化与风控/run_full_pipeline.py` 负责。每一步完成后都会写入按自然周分组的本地检查点，失败或中断后可以从第一个未完成步骤继续。
