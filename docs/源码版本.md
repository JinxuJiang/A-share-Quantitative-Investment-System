# 源码版本

本展示仓库由三个独立生产仓库的当前工作区快照整理而成，不包含原仓库的 `.git` 目录。

| 展示模块 | 来源项目 | 基准提交 |
| --- | --- | --- |
| 01截面选股模型 | 截面多因子模型 | `a20cce6` |
| 02市场仓位模型 | 市场预测模型 | `71af289` |
| 03组合优化与风控 | 组合风控层 | `142fe64` |

截面模型快照还包含迁移后尚未在来源仓库提交的 5 日生产配置路径调整。该调整用于将旧的绝对路径改为项目相对路径，不改变模型参数。

展示仓库主动排除了以下内容：

- 三个来源仓库的 Git 历史；
- 原始与加工数据、缓存和模型产物；
- 发布信号、完整回测明细和逐笔交易记录；
- 带有本机绝对路径的历史调参输出；
- 本地开发环境、临时文件和实验 notebook。
