# 源码版本

本展示仓库由三个独立生产仓库的当前工作区快照整理而成，不包含原仓库的 `.git` 目录。

| 展示模块 | 来源项目 | 基准提交 |
| --- | --- | --- |
| 01截面选股模型 | 截面多因子模型 | `0e0a82f` |
| 02市场仓位模型 | 市场预测模型 | `30dca4e` |
| 03组合优化与风控 | 组合风控层 | `506197c` |

三个快照均对应来源仓库的已提交版本。展示仓库只对目录名称做了必要适配：生产项目名称映射为 `01截面选股模型`、`02市场仓位模型` 和 `03组合优化与风控`，模型参数和业务逻辑保持不变。

展示结果属于固定历史快照，不会因为源码同步自动改写。只有重新运行、复核并明确更新结果后，`results` 中的指标和图表才会变化。

展示仓库主动排除了以下内容：

- 三个来源仓库的 Git 历史；
- 原始与加工数据、缓存和模型产物；
- 发布信号、完整回测明细和逐笔交易记录；
- 带有本机绝对路径的历史调参输出；
- 本地开发环境、临时文件和实验 notebook。
