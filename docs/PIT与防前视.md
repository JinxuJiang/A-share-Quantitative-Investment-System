# PIT 与防前视设计

本系统将“决策时点真实可见的信息”作为数据进入模型的必要条件，而不只按报表期或自然日期进行简单匹配。

核心控制包括：

- 财务指标依据正式披露时间进入特征集；同一报告期存在后续修订时，不将修订结果回填到历史决策时点。
- 行情特征、标签和实际交易价格按明确的信号生成与成交时序对齐。
- 训练集、验证集和预测集按时间推进，不进行破坏时间顺序的随机抽样。
- 模型冻结版本记录配置、训练范围和数据口径，数据口径变化后不复用不兼容的冻结模型。
- 回测模块独立检查信号日期、持仓生效日期和收益归属日期。

后续将结合最小示例数据补充字段级可得时间说明和自动化因果性测试。
